## 🚀 使用流程

### 一、创建盘点任务

#### 步骤：

1. **进入盘点页面**
   - 点击左侧菜单 **"盘点"**

2. **创建新任务**
   - 点击 **"创建盘点任务"** 按钮
   - 系统会自动：
     - ✅ 获取当前仓库所有工具
     - ✅ 生成盘点清单（包含所有工具）
     - ✅ 设置初始统计数据

3. **任务信息**
   ```
   任务名称：盘点任务 2026/3/10
   应盘数量：100 个工具
   已盘数量：0
   状态：进行中
   ```

---

### 二、扫码盘点

#### 方式 A：使用扫码枪（推荐）

1. **将光标定位到输入框**
   - 系统会自动聚焦

2. **扫描工具二维码**
   - 使用扫码枪扫描二维码
   - 资产编号自动填入输入框

3. **按回车确认**
   - 系统自动识别工具
   - 弹出确认对话框

4. **确认工具状态**
   - 选择实际状态（可用/借出/损坏等）
   - 可添加备注说明
   - 点击"确认"

#### 方式 B：手动输入

1. **在输入框中键入资产编号**
   - 例如：`TL-001`

2. **按回车确认**
   - 后续流程同上

---

### 三、进度跟踪

#### 实时统计看板：

```
┌─────────────────────────────────┐
│  进度条：████████░░ 80%         │
│  已扫描：80 / 100               │
├──────────┬──────────┬──────────┤
│   ✅相符  │   ➕盘盈  │   ➖盘亏  │
│    75    │    3     │    2     │
└──────────┴──────────┴──────────┘
```

#### 颜色标识：

| 颜色 | 含义 |
|------|------|
| 🟢 绿色 | 相符（match）- 实物与记录一致 |
| 🔵 蓝色 | 盘盈（surplus）- 实物存在但系统无记录 |
| 🔴 红色 | 盘亏（shortage）- 系统有记录但找不到实物 |

---

### 四、特殊情况处理

#### 场景 1：发现未登记的工具（盘盈）

**操作流程：**
1. 扫描工具二维码
2. 系统提示："未找到资产编号为 XX 的工具记录"
3. 点击"确定"记录为盘盈
4. 填写工具信息（名称、分类、状态等）
5. 保存到库存

**结果：**
- ✅ 工具添加到系统
- ✅ 标记为盘盈
- ✅ 计入统计数据

---

#### 场景 2：找不到实物（盘亏）

**操作流程：**
1. 在清单中找到该工具
2. 点击工具条目
3. 选择"盘亏"
4. 填写原因（如：丢失、被盗等）

**结果：**
- ✅ 工具状态改为"遗失"
- ✅ 软删除（保留历史记录）
- ✅ 标记为盘亏

---

#### 场景 3：状态不符

**示例：**
- 系统记录：可用
- 实际状态：损坏

**操作流程：**
1. 扫描工具
2. 选择实际状态为"损坏"
3. 系统自动标记为"状态调整"
4. 更新工具状态

**结果：**
- ✅ 工具状态从"可用" → "损坏"
- ✅ 记录差异原因
- ✅ 计入准确率统计

---

### 五、完成盘点

#### 结束流程：

1. **点击"完成盘点"按钮**
   - 位于页面底部

2. **系统检查**
   - 如果有未盘点的工具：
     ```
     提示：还有 5 个工具未盘点
     [继续盘点] [结束并标记为盘亏]
     ```

3. **确认结束**
   - 未盘点的工具自动标记为盘亏
   - 任务状态改为"已完成"
   - 生成盘点报告

## 💡 最佳实践

### 1️⃣ 盘点前准备

- ✅ 整理仓库，确保工具摆放整齐

### 2️⃣ 多人协同盘点

**场景：** 大型仓库需要多人同时盘点

**方案：**
1. 创建多个盘点任务（按区域划分）
   - 任务 1：A 区工具
   - 任务 2：B 区工具
   - 任务 3：C 区工具

2. 分配给不同人员
   - 张三负责 A 区
   - 李四负责 B 区
   - 王五负责 C 区

3. 汇总报告
   - 分别完成各自任务
   - 管理员查看整体统计

### 3️⃣ 定期盘点建议

| 频率 | 适用范围 | 建议 |
|------|---------|------|
| **每日** | 高价值工具 | 抽查 5-10 件关键工具 |
| **每周** | 常用工具 | 盘点 20-30 件 |
| **每月** | 全部工具 | 全面盘点一次 |
| **每季** | 深度盘点 | 彻底清理 + 审计 |

### 4️⃣ 提高准确率技巧

   - 一人扫码，一人确认
   - 减少误操作

2. **分区进行**
   - 避免重复或遗漏
   - 完成后做标记

3. **拍照留证**
   - 对盘盈/盘亏工具拍照
   - 上传到附件作为证据

## 🔧 技术细节

### 数据库触发器

系统会自动维护以下统计数据：

```sql
-- 自动更新任务的统计字段
CREATE TRIGGER trg_update_inventory_stats
AFTER INSERT OR UPDATE ON inventory_items
FOR EACH ROW
EXECUTE FUNCTION update_inventory_task_stats();
```

**更新逻辑：**
- `scanned_items` = 已扫描数量
- `match_count` = 相符数量
- `surplus_count` = 盘盈数量
- `shortage_count` = 盘亏数量

### API 调用示例

```typescript
// 创建盘点任务
const createTask = async () => {
  const tools = await supabase
    .from('tools')
    .select('id, asset_code, status')
    .eq('warehouse_id', currentId)
    .is('deleted_at', null)
  
  const task = await supabase
    .from('inventory_tasks')
    .insert({
      warehouse_id: currentId,
      total_items: tools.length,
      status: 'in_progress'
    })
  
  const items = tools.map(tool => ({
    task_id: task.id,
    tool_id: tool.id,
    expected_status: tool.status,
    actual_status: null
  }))
  
  await supabase.from('inventory_items').insert(items)
}
```

## ❓ 常见问题

### Q1: 盘点中途有人借还工具怎么办？

**A:** 系统会记录创建任务时的快照。盘点期间：
- ✅ 可以正常借还工具
- ⚠️ 但新借出的工具不会出现在本次盘点清单中
- 💡 建议：盘点期间暂停借还，或在盘点完成后重新盘点相关工具

### Q2: 扫码枪不工作怎么办？

**A:** 
1. 检查扫码枪是否连接到电脑
2. 测试在其他应用中是否能正常使用
3. 确保输入框已获得焦点
4. 尝试手动输入资产编号

### Q3: 盘点错了可以修改吗？

**A:** 
- ✅ 可以！在任务完成前，随时可以重新扫描已盘点的工具
- ✅ 系统会覆盖上次的盘点结果
- ⚠️ 任务完成后无法修改，但可以查看历史记录

### Q4: 如何查看历史盘点记录？

**A:** 
1. 在任务列表中，点击已完成的任务
2. 切换到"报告"标签
3. 查看当时的盘点详情

### Q5: 盘盈的工具如何添加到库存？

**A:** 
- 扫描时系统会提示是否记录为盘盈
- 确认后会自动创建工具记录
- 需要补充完整信息（名称、分类等）

## 📊 数据统计说明

### 准确率计算

```
准确率 = (相符数量 / 已盘点数量) × 100%

示例：
已盘点：95 件
相符：90 件
准确率 = (90 / 95) × 100% = 94.7%
```

### 差异类型说明

| 类型代码 | 中文 | 说明 | 处理方式 |
|---------|------|------|----------|
| `match` | 相符 | 实物与记录完全一致 | 无需处理 |
| `surplus` | 盘盈 | 实物存在但系统无记录 | 新增工具 |
| `shortage` | 盘亏 | 系统有记录但找不到实物 | 标记遗失 |
| `status_mismatch` | 状态不符 | 实物状态与记录不同 | 调整状态 |

## 🆘 故障排除

### 问题：创建任务失败

**错误提示：** "当前仓库没有工具"

**解决方案：**
1. 确认已选择正确的仓库
2. 检查是否有工具记录
3. 先添加工具再创建盘点任务

---

### 问题：扫码后没反应

**可能原因：**
1. 输入框未获得焦点
2. 扫码枪配置问题
3. 网络延迟

**解决方案：**
1. 点击输入框确保聚焦
2. 重启扫码枪或更换 USB 接口
3. 等待几秒后重试

---

### 问题：统计数据不准确

**可能原因：**
- 浏览器缓存
- 数据同步延迟

**解决方案：**
1. 刷新页面（F5）
2. 切换到其他页面再返回
3. 退出重新进入
