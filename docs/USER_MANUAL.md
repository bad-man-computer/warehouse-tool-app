# 用户操作手册

## 一、登录

1. 打开系统地址，进入登录页。
2. 输入 **用户名** 和 **密码**，点击「登录」。
3. 演示环境可使用：用户名 `demo`，密码 `demo`。

## 二、界面与语言

- **网页端**：左侧为导航菜单（首页、工具管理、借还、维修、盘点、报表），右侧为内容区；左上或底部可切换当前仓库。
- **手机端**：底部 Tab 为「首页 / 扫码 / 工具 / 我的」，扫码为快捷入口。
- **语言**：在「我的」页面可切换「中文 / English」，切换后整站即时生效。

## 三、仓库切换

- 登录后可在侧栏或「我的」中选择 **中国仓库（CN）** 或 **新加坡仓库（SG）**。
- 普通用户仅能查看所属仓库；仓库经理可管理指定仓库；管理员可查看全部仓库。

## 四、工具管理

- **工具列表**：按仓库查看工具，支持按 **资产编号、名称、状态、位置** 筛选。
- **工具状态**：  
  可用、借出、已归还、损坏、维修中、遗失。  
  列表中以不同颜色标签区分。
- **扫码**：手机端在「扫码」页扫描工具上的二维码，可快速查看详情或进行借还。

## 五、借还流程

1. **借出**：选择工具，填写借用人姓名、部门、联系方式、预计归还时间，确认借出；工具状态变为「借出」。
2. **归还**：选择已借出工具，确认归还时间，选择归还状态（正常/损坏），提交后工具变为「已归还」；检查通过后可重新入库为「可用」。
3. **批量**：可多选工具后批量借出或归还。
4. **逾期**：系统会标记逾期未还工具并支持提醒（具体以实际功能为准）。

## 六、维修管理

1. **报损**：对工具进行「报损」操作，可上传损坏照片、描述问题，工具状态变为「损坏」。
2. **送修**：对损坏工具进行「送修」，填写维修商、费用、预计完成时间，状态变为「维修中」。
3. **结果**：维修完成后标记「已修复」（工具回归可用）或「报废」。

## 七、库存盘点

1. 在「盘点」中发起盘点，选择仓库，生成盘点清单。
2. 手机端可扫码逐条核对。
3. 对盘盈、盘亏进行标记，完成后生成差异报告。

## 八、报表统计

- **首页看板**：各状态工具数量、分布图表。
- **借用统计**：高频借用人员、部门分析。
- **维修分析**：故障率、维修成本等。
- **仓库对比**：中国与新加坡仓库数据对比。

## 九、我的

- 查看当前用户与角色。
- 切换 **语言**（中/英）。
- 切换 **当前仓库**。
- **退出登录**。
